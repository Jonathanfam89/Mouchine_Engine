Users are required to download the latest cmake and git to able to run and build the game engine and as well as fetch from git repos
https://cmake.org/download/
https://git-scm.com/install/

user are also recommended to install the visual studio workloads of desktop development with c++ and ./net development.

we have 8 project in the solution and we touched Game and Engine project and GameScripts while the rest is the library that are Pre-Complied
we first need to make sure we have the Assets,Logs,Engine,Game,cmake,Shaders,extern, scripts and Mono are present before running the script_build.
after running cmake/ build.bat file set game as the set up project and build the project accordingly 
or you can use the script_run to run the debug build .exe

as you edit any .cs files you just need to build the project again for the c# project to take affect the cmake and the .csproj will add the c# dll to the engine

===========================================================================================================

Player Controls

- Movement
  W			Glide (Hold and is the air)
  A                    	Walk Left
  D                   	Walk Right
  Spacebar             	Jump
  J			Dash
  K			Roll
  L			Wall Kick

System

- IMGUI
  Left click     	Control IMGUI Windows
  Ctrl + T		Tile Map Visibility 
  

- Debug
  F1                    Toggle on/off debug mode
  F2			Able/Disable step by step mode
  F3			When in step mode, advances frame by frame
  F4			FPS counter in game 

- Batch Rendering
  1                  	Spawn 2500 entities on screen
  2                   	Destroy all entities

- Audio
  M			Pause the BGM sound

- Game State
  ESC			Quit the game
  P/Esc                 Pause Menu
